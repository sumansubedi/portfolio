---
title: Why I own my tools
date: 2026-02-01
summary: A content hub I can edit for the next decade beats a host I have to migrate off in two years.
---

This site is the first thing I've built where the goal isn't to launch — it's to keep.

Most portfolios are job-hunting tools: spun up fast, abandoned faster. I wanted the
opposite. Something I own outright, write the code for directly, and can keep editing for
years without fighting a platform that changed its mind.

That decision shaped every choice. Plain files for content. A framework with a big enough
community that help still exists in five years. And — because I test software for a living —
a build that proves itself before it ships.

The rest of this site runs its own checks in CI. If something here is broken, the deploy
never happens. That felt like the right way to introduce myself.
